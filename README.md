# 📌 UTS & UAS Algoritma Pemrograman

Repository ini berisi proyek UTS dan UAS mata kuliah **Algoritma Pemrograman** yang dikembangkan menggunakan bahasa pemrograman **C++**. Proyek ini dibuat dengan menerapkan berbagai konsep dasar pemrograman yang telah dipelajari, seperti:

- Variabel dan Tipe Data
- Operator
- Pengkondisian (if-else, switch-case)
- Perulangan (for, while, do-while)
- Fungsi
- Pointer
- Struktur Data Dasar

## 🚀 Cara Menjalankan Program

1. Pastikan Anda telah menginstal **compiler C++**, seperti GCC atau MinGW.
2. Clone repository ini ke komputer Anda menggunakan perintah berikut:
   ```sh
   git clone https://github.com/username/UTS_UAS_AlgoProg.git
   ```
3. Masuk ke direktori proyek:
   ```sh
   cd UTS_UAS_AlgoProg/src
   ```
4. Kompilasi dan jalankan program:
   ```sh
   g++ uts.cpp -o uts && ./uts
   ```
   atau untuk program UAS:
   ```sh
   g++ uas.cpp -o uas && ./uas
   ```
